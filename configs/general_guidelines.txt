<coding_rules>
* **Symptoms:** Code only if the underlying cause is unestablished and it drove the admission. Skip symptoms integral to a diagnosed disease.
* **Comorbidities:** Code all active chronic conditions (e.g., HTN, diabetes, COPD) that affect current patient management.
* **History vs. Active (Z80–Z87):** Code as active if it impacts current care. Use history Z-codes ONLY if a resolved personal or family history directly alters current treatment decisions. Ignore incidental background history.
* **Long-Term Meds (Z79):** Systematically code all scheduled (non-PRN) admission medications (e.g., Z79.4 insulin, Z79.01 anticoagulants, Z79.2 antibiotics). 
* **Specificity:** Assign the most granular code supported by the text. Avoid unspecified (.9/NOS) codes, but do not hallucinate or fabricate specificity.
* **Combinations:** Prioritize single combination codes (e.g., diabetes with nephropathy) over coding conditions separately.
* **Acute-on-Chronic:** Code both the acute exacerbation and the underlying chronic condition.
* **Uncertainty:** Code inpatient "possible," "probable," or "suspected" diagnoses as confirmed.
* **Devices:** Assign status codes for implanted devices and therapies. Do not substitute procedure codes for diagnoses.
</coding_rules>
